# Unity 2D Interaction Demo (Prototype)

## Overview
This is a simple Unity 2D project created in 2025 to practice and showcase interaction logic, UI management, and scene handling.

## Features
- 2D movement with keyboard input
- Scene transition when entering a house
- Chest interaction with on-screen dialog box
- Basic trigger logic implemented in C#
- Assets used from [Kenney.nl](https://kenney.nl)

## Tools & Support
- Made in Unity 2022+  
- Code written in C# (basic scripting)  
- Used ChatGPT for debugging support and learning new techniques  

## Purpose
This project was created as a personal learning experience, not for commercial release.  
Focus areas include:
- Trigger events and interactions
- UI dialog systems
- Scene loading between areas
