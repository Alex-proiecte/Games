# 2D Platformer Prototype (Buildbox)

## Overview
This project began in 2016 as my very first attempt at building a game.  
In 2025, I revisited the concept and rebuilt it in Buildbox to better reflect my current skills in game logic and structure.

## Timeline
- 🕹️ 2016: Initial prototype, created as a personal learning project  
- 🔁 2025: Complete rebuild using Buildbox, improved logic and gameplay

## Features
- Side-scrolling platformer with keyboard input (arrow keys + space)
- Basic levels with jump puzzles and obstacles
- Uses placeholder art from [Kenney.nl](https://kenney.nl)

## Purpose
Not intended for release – the goal is to show personal progress in game development between 2016 and 2025.
