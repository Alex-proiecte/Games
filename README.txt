# 2D Platformer Prototype (Buildbox)

## Overview
A work-in-progress 2D platformer built in Buildbox (2025), intended as a personal project to showcase my understanding of game logic and gameplay structure.

## Features
- Classic side-scrolling platformer
- Simple keyboard controls: arrow keys to move, space to jump
- Multiple obstacles and a basic level layout
- All assets used are free placeholders from [Kenney.nl](https://kenney.nl)

## Focus
This prototype focuses on:
- Gameplay mechanics
- Level design and flow
- User input logic
- Structuring a game using Buildbox's visual system

## Status
🛠️ Not published – runs in Buildbox preview  
🎯 Goal: To demonstrate game development skills, not visual design

## Notes
This project is not intended for release and uses placeholder assets for testing purposes only.
